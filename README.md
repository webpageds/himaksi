# HIMAKSI — Dari Sejarah Menuju Arah Perubahan

Website presentasi statis siap untuk GitHub Pages.

## Pembaruan isi
Slide 3 kini memuat sejarah HIMAKSI UNPAM Serang berdasarkan dokumen sejarah yang diberikan: tanggal berdiri 21 September 2023, latar belakang pembentukan, proses MUBES/musyawarah, serta peran organisasi. Slide lain mempertahankan visual dari PDF sumber.

## Isi folder
- `index.html` — struktur website
- `style.css` — desain responsif
- `script.js` — navigasi galeri dan presentasi
- `assets/slide-01.jpg` sampai `slide-10.jpg` — visual slide

## Publish di GitHub Pages
1. Ekstrak ZIP.
2. Upload semua isi folder ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
5. Tunggu deployment selesai dan buka URL yang disediakan GitHub.

Catatan: teks dalam slide ditampilkan sebagai gambar untuk menjaga komposisi visual. Slide 3 telah didesain ulang agar isi sejarah resmi yang diberikan tidak lagi berupa placeholder.
